# AI Snake (in AI_Game folder)

This repository's playable game and server code are located inside the `AI_Game/` directory.

Quick start:
- Install dependencies: `pip install flask`
- Run: `python3 AI_Game/app.py` or `cd AI_Game && python3 app.py`
- Open: `http://localhost:5000`

See `AI_Game/README.md` for full details.
